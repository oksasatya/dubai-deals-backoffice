## Dubai-Deals-Backoffice

This Project is a backoffice for the Dubai Deals project. It is a web application that allows the admin to manage the deals, users, and categories of the Dubai Deals project.
Created with next.js, typescript, and styled-components.

## Technologies
- Next.js
- Typescript
- Styled-components
- Axios
- Tailwindcss
- React-hook-form
